# @turtl/eslint-config

## 0.3.0

### Minor Changes

- Extraction du package du monorepo vers un dépôt dédié, renommé `@turtl/eslint-config`
- Les plugins ESLint sont désormais des `dependencies` et `eslint` une `peerDependency`
- Export `@turtl/eslint-config/rules` pour utiliser les règles custom seules
- Ajout de la règle `@custom/no-multiple-spaces-in-tagged-templates` détectant les espaces multiples dans les templates taggés `html`
